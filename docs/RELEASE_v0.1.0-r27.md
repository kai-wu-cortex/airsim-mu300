# R27 · 信号、短信兼容与来电号码修复（开发预览）

2026-11-24，基于 develop，沿用预览频道。用户确认当前改动已测试，并明确要求
commit、push 和发布。本次 USB 未连接，用户明确授权跳过新的设备预检；不把历史
预检或用户测试声明扩展为所有固件、短信后端和新内核均已验收。

## 本版变更

- **信号**：旧 RPC 无读数时兼容 `mu300dash signal`，校验采样时间及 RSRP，保留
  通话/切卡保护。本地状态和云端心跳共用读数，不伪造信号。此前 USB U30 Air 候选
  已确认从空值恢复为有效 RSRP，客户端显示仍取决于其对应版本的数据映射。
- **短信**：优先原生短信目录；缺失时支持指定 E5 JSON 收件库（SIM 1），再支持
  私有完整快照。失败保留待交付记录；原生恢复后自动重新选用。LuCI 增加独立的
  手机短信链路诊断，区分网页列表和手机同步状态。
- **短信发送兼容**：仅当原发送包装器不存在时，才允许调用哈希固定、broker 状态
  已确认的已装原生工具；保持退出/回执校验和未知结果不重发，不直接抢占 AT 串口。
- **来电号码**：补齐 `tel:`、用户部分 `user=phone` 和旧 Agent 的 `数字@域名`。
  单次解码，保留 `+`/`00`；分机、上下文、匿名及错误编码不强行转号码。相同号码
  的 URI/纯数字形式变化不更换通话 ID，不修改拨号/SMS 目标或认证。
- **离线完整性**：固定 Agent 基线、Go vendor 和许可证随源码保存；17 项固定
  音频/ALSA/DSP/内核相关输入随独立恢复附件保存，缺失或哈希不符拒绝恢复。
  从空缓存、无上游工作树的环境重建，构建不依赖 Go 模块代理。

## 安装和验证

停止通话和短信任务后，在支持的设备运行：

```sh
cd /tmp
wget -O airsim-install.sh https://github.com/kai-wu-cortex/airsim-mu300/releases/download/v0.1.0-r27/install.sh
cat airsim-install.sh
sh airsim-install.sh --check
sh airsim-install.sh --install
```

LuCI 更新器需开启预览频道。配对与配置保留，默认 PCM 增益仍为 0 dB，未改变
系统、内核或音频采样率。昨日短信/信号候选完成安装和文件校验，原生短信链路
显示 ready、配对/身份/配置保留、未重启设备；其后号码补丁完成独立自动化回归。
用户于本次发布请求确认已测试；未提供逐项测试明细。发布过程不安装设备、不发起
真实通话、短信或录音。自动检查覆盖 Go race/vet、全部 Node 测试、隔离 Agent、
共享号码用例、源码补丁重放、离线恢复、安装 fixture、包签名及源码/许可证。
