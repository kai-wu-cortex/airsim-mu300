## 页面对应

顶部固定九个入口，顺序与参考一致；手机窄屏改为页面选择器。

| 页面 | 卡片与内容 |
|---|---|
| 设备概览 | 设备状态、启动服务、配对客户端、拨号与通话；配对管理从配对卡进入 |
| 连接 | 连接模式、Relay 地址、端口与接口、运行状态、保存 |
| 联网 | 上网方式、连接 Wi-Fi、已保存的 Wi-Fi、管理页面访问、设备限制；桌面四列，限制卡在管理访问卡下面 |
| 来电转发 | 开关、推送渠道、推送哪些状态、请求与正文、运行状态、测试与最近投递 |
| 短信 | 收件列表与批量管理、独立发送卡 |
| 维护 | 备份、恢复、插件更新、可选配件、5.4 上网体检、诊断导出、版本说明 |
| 外观与设置 | 外观、显示、关于；主题/密度/背景使用分段控件 |
| 蓝牙 | 开关、本机蓝牙、已配对设备、附近设备、说明 |
| 音频 | 音频配件包、刷机后自检、切换内核 |

原 manage/extensions/kernel/messages 书签映射到新页面，保留配对管理深层入口。
LuCI 菜单只显示九个主入口。所有资源继续按内容摘要命名，插件升级后重新打开页面即可加载新版本。

## 接口与冲突评审

- 复用 U30 已有的认证 RPC、状态机与操作回执。共享控制器使用 baseclass，只有路由入口使用 view；
  避免 LuCI 自动实例化依赖时把另一个页面挂到主视口。
  已对照 [LuCI View 初始化实现](https://github.com/openwrt/luci/blob/master/modules/luci-base/htdocs/luci-static/resources/luci.js) 核对。
- 联网开关映射 Wi-Fi / 蜂窝＋热点；高级选择保留仅蜂窝模式。布局未知时禁用。
  防火墙只读状态分开提供配置值与实际规则，读取失败显示未知，不能将未知渲染成成功关闭。
- 修改、扫描与备份仍需确认、关闭服务、通话/音频/短信空闲检查与共享维护锁。
  开关不乐观提交状态；任务完成后读取实际值，失败或断网不自动重发。
- 不复制 F50 的射频、内核或蓝牙驱动假设；未验证音频组合继续禁用。
  内核页只生成手动命令，不执行内核切换；不会因为改 UI 放开 ABI 校验。
- 通知继续使用现有结构化 HTTPS 渠道。参考页中本项目没有的逐类通知筛选、自由模板、
  测试投递、投递历史等明确显示不可用，不伪装成功或擅自发送测试通知。
- 配对确认、短信发送/删除确认、未知结果保护不变。AirSIM iOS/Android 与上游工作树保持原样。
- 外观仍保存在当前浏览器，尊重已保存偏好；新浏览器默认系统主题＋玻璃卡片。
  CSS 限定 AirSIM 容器，旧浏览器和减少透明度设置回退为实色，保留减少动效与键盘操作支持。
