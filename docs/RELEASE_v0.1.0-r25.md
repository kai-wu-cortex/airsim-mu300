# R25 · 新版 LuCI、通话音量与配对显示修复（开发预览）

2026-11-14，基于 `develop` 发布。此前 R24 仅作为独立来电修复候选使用，
本次使用 R25 避免同版本不同内容。保持 Pre-release：候选安装和基础检查已通过，
不将其等同于新增功能的完整通话验收。本仓库不修改或发布 AirSIM 客户端、Relay。

## 必须先确认兼容性

**历史版本选型：R16 适用于 1031 之后的 mu300-linux 系统版本线；R12 适用于
1031 之前的旧系统版本线，不得跨版本线混装。** 日期不能替代设备、内核配置与 ABI 检查。

R25 一体 APK 当前仅面向 **U30 Air / aarch64 / OpenWrt APK v3**：

- 已验证基础系统：mu300-linux v2026.10.30.1 / OpenWrt 25.12.6。
- 音频内核：`5.4.254-gb50db5b6224c`。
- 内核配置 SHA-256：`1057cb97e0d2d7f26816e8bf7841faac1153833a01d4893cdc196b75ae6356b3`。
- **U30L、F50、6.18.60、7.3.1 及更高版本的音频没有完成本项目实机验收。**
  7.3 切换入口不等于 7.3 音频适配，6.18/7.3 音频安装仍禁用，不绕过 ABI 检查。

## 本版变化

- **新版 LuCI**：九页导航、独立短信页和卡片布局；修复表单截断、跨栏阴影及过大外边距。
  已知 MU300 系统首页嵌入设备状态、服务、配对及通话卡片；未知首页保留原样。
  布局参考 shangjie1998/airsim-f50-openwrt，保留 U30 接口与硬件保护。
- **通话音量**：外观与设置页提供“我听对方 / 对方听我”独立 0～12 dB PCM 增益，
  默认均为 0 dB，带峰值限制；局域网、云端和接通前下行提示音复用处理。
  先关闭服务再保存，下一次启动生效。增益不改善采样率，过大仍可能增加底噪或失真。
- **配对码显示**：设备时钟与浏览器不同也按设备剩余有效时间显示验证码与倒计时。
  保留配对认证和有效期校验，不修改系统时钟、不清除已有配对。
- **配对管理**：查看指纹、最近认证活动并定向移除；活动通话、媒体或未知状态禁止移除。
- **设备扩展**：受保护的配置备份/恢复、已有蓝牙控制器管理、联网/热点及 5.4 流卸载维护、
  默认关闭的事件通知、安装自检。未知网络布局或缺失硬件时保持不可操作。
- **短信及状态兼容**：原生发送参数和成功回执兼容、独立短信管理页、运营商与信号回退，
  失败清除旧状态；未知发送结果不换接口重发。保留短信生产者身份及恢复一致性。
- **7.3 手动内核入口**：识别固定版本的原生更新器，旧版仅备份后补两处白名单；
  默认只检查，写入要求可信本地包摘要、设备匹配及空闲状态。保留原生回退，不自动切换或重启。
- **来电与 Watch v2**：SIP 数字号码格式变化保留同一通话身份；有效原生 UUID 统一用于推送，
  不透明旧 ID 保留兼容。已确认终态按完整通话身份保存，查询失败不假报挂断，
  旧通话不得干扰新通话。用户报告的 CallKit 接听退出仍需受影响设备验证，不宣称全部解决。

保留 R23 的 Tailscale 私网 IP 配对、云端接收缓冲，以及既有早期媒体、号码、电量与音频一体安装。
云端接通前公告仍需支持 `early_media_version:1` 的客户端。

## 安装、设置与回退

LuCI 更新器需开启预览频道。先结束通话和短信任务，保留配置与可信旧包。在适用设备执行：

```sh
cd /tmp
wget -O airsim-install.sh https://github.com/kai-wu-cortex/airsim-mu300/releases/download/v0.1.0-r25/install.sh
cat airsim-install.sh
sh airsim-install.sh --check
sh airsim-install.sh --install
```

首次缺失 DSP 固件时尝试固定上游 HTTPS，失败用固定备用副本；两者核对相同摘要，已有固件保留。
备用副本来自公开上游，不来自用户设备；其独立许可未明确，项目许可证不覆盖该固件。

安装后刷新 LuCI。AirSIM 用户听对方偏小时，在“外观与设置 → 通话音量”仅将下行试调至 +3 dB，
上行保持 0 dB；关闭服务后保存，再启动并由用户手动验收。

回退应先结束通话、关闭服务，再安装匹配同一设备的可信旧包；不要跨内核强装。
回退至 R22 或更早版本前清空 Tailscale 接口设置，避免旧版严格解析失败。
仅做音量回退可把两项设回 0 dB，无需降级插件。
