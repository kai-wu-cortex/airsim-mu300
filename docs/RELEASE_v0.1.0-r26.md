先结束通话与短信任务，在兼容设备运行：

```sh
cd /tmp
wget -O airsim-install.sh https://github.com/kai-wu-cortex/airsim-mu300/releases/download/v0.1.0-r26/install.sh
cat airsim-install.sh
sh airsim-install.sh --check
```
