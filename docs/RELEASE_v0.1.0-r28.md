# R28 · 云端接听身份与信号采样时间修复（开发预览）

2026-11-27，基于 develop，沿用预览频道。本项目是独立集成，不是 MU300 Linux/Audio 官方发布。

## 本版变更

- **接听后通话界面消失**：同一 CLCC 槽位的完全对应大陆 11 位移动号码与显式
  `+86` / TEL 格式转换，保持原 call ID / UUID / generation，避免把接通后的号码
  格式变化当成新通话并结束原云端会话。不按尾号匹配，不放宽拨号、短信或认证。
  不同号码、方向改变、已接通槽重新进入响铃/拨号仍按原保护生成新身份。
- **Relay 状态通知**：只识别精确的 `{event, role}` 通知，避免误作为控制命令报错；
  携带额外动作或身份字段仍经过原校验。
- **信号采样时间**：Agent 本地状态和云端心跳新增可选 `signal_observed_at_ms`
  （Unix 毫秒），取成功 AT+CSQ 返回时刻。读取失败且没有替代读数时保留原值和
  原时间；成功返回未知/无效值且没有厂商回退时清除两者。重复心跳不延长有效期。
- 保留 R27 短信兼容、号码解析、固定源码/Go vendor 和独立离线恢复附件。

## 已验证与限制

11 月 25 日接听候选由用户按自动模式、App 退出后台、锁屏 CallKit 接听的场景复测，
确认接听和双向声音正常。诊断显示全程保持同一通话身份，真实挂断后释放媒体。
该实测使用独立 iPhone 候选；客户端的路由等待优化不包含在本插件包内。
本次完整 R28 包没有新的整包设备安装验收，不将历史短通话扩展为所有硬件/网络均已通过。

**厂商 RSRP 的云端灵动岛显示仍未完整解决。** 此前 U30 Air 的有效读数曾来自
`mu300dash` RSRP，CSQ 为未知值时，仍保留旧信号回退，但不会给它伪造 CSQ 采样时间。
新版客户端要求时间时可能继续显示未知；需要另行明确厂商原生 `ts` 与度量类型的
跨端协议。不能把安装 R28 描述为所有固件的云端信号显示均已恢复。
不生成虚假 SIM 1/2；支持新字段的客户端按真实时间处理过期，Relay 应原样保留时间。

自动检查覆盖桥和隔离 Agent 的 Go race/vet、全部 Node 测试、离线构建及补丁重放、
安装 fixture、APK 签名/包内容、源码/许可证和依赖哈希。
本次准备阶段未检测到 USB U30 Air，尚未完成新的只读设备预检。发布过程不安装设备、不拨号、不发短信或录音。

## 安装与附件

停止通话和短信任务后，在支持的设备运行：

```sh
cd /tmp
wget -O airsim-install.sh https://github.com/kai-wu-cortex/airsim-mu300/releases/download/v0.1.0-r28/install.sh
cat airsim-install.sh
sh airsim-install.sh --check
sh airsim-install.sh --install
```

LuCI 更新器需开启预览频道。保留配置与配对，系统、内核、采样率和默认 PCM 增益不变。
超过16条配对不可直接降级至 R25 或更早旧桥。

- `luci-app-airsim-0.1.0-r28.apk`：完整签名一体安装包。

- `airsim-mu300-0.1.0-r28-recovery.tar.gz`：17 项固定构建/音频恢复输入，普通升级无需下载。
- 安装器、公钥、`SHA256SUMS` 与校验清单签名。
