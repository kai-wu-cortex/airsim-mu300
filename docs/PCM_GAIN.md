## 设置

两个方向默认都是 **0 dB**，逐字节保留原始输出。允许整数 **0～12 dB**。
3 dB 约为 1.41 倍振幅、6 dB 约为 2 倍，不能将振幅倍数当成主观响度倍数。
应先确认偏小方向，再从 3 dB 小幅尝试；没有实机证据支持给所有设备默认加大。

安装包含此功能的候选后，打开 **LuCI → 服务 → AirSIM → 外观与设置 → 通话音量**：

1. 先结束通话，在设备概览关闭 AirSIM 服务。
2. 调整“我听对方（下行）”或“对方听我（上行）”，点击“保存音量”。本次反馈可先只将下行设为 +3 dB，上行保持 0 dB。
3. 回到概览启动服务，再由用户手动测试音量。保存不会自行重启服务或发起通话。

“恢复原音量”只把表单两项设为 0 dB，仍需点击保存；“重新读取”会用设备保存值
替换表单草稿。状态轮询不会覆盖未保存的选择。配置读取失败、服务运行或状态
未知时不允许保存；保存结果未知时必须先重新读取，界面不会自动重发。

保存沿用维护写权限、独占运行锁及基带/媒体/短信空闲检查。后台在临时副本中
只修改两项 UCI 值并核验，原配置或待提交项发生变化则拒绝写回；不改动配对、
接口、服务开关或其它选项。音量保存在设备，外观偏好仍仅保存在浏览器。

也可在设备 SSH 修改 `/etc/config/airsim`：

```sh
# 示例：只增强 AirSIM 用户听到的声音；不会立即改变正在运行的服务。
uci set airsim.main.pcm_downlink_gain_db='3'
uci set airsim.main.pcm_uplink_gain_db='0'
uci commit airsim
```

确认没有通话、媒体或短信任务后，通过已有管理流程关闭并启动 AirSIM 服务，
重新连接客户端生效。不要在通话中执行重启。旧配置缺少这两个选项时自动采用
0 dB；连接管理页保存不覆盖这些 UCI 项。恢复原音量时把两项设回 `0`，空闲后
重新启动服务。

手动运行桥也支持 `--pcm-downlink-gain-db` 和 `--pcm-uplink-gain-db`。
异常配置在准备硬件前拒绝启动。配置在服务启动时读取，各音频流独立保留
处理状态；不会因每帧重新计算而重置限幅器。

## 峰值限制与诊断

增益启用时使用即时压低峰值、50 ms 指数恢复的限幅器，输出不超过 ±30000
（S16LE 满量程为 -32768～32767），防止有符号溢出。限幅会改变大声片段的
动态，不能保证任何输入均无失真；增益过大也会放大底噪。它不是降噪、回声消除、
自动响度归一化或采样率升级，也不能修复输入本身已经失真的声音。

现有音频状态中增加：

- `downlink_gain_db` / `uplink_gain_db`：配置增益。
- `downlink_limited_samples` / `uplink_limited_samples`：本次桥进程运行以来被限幅器
  衰减的非零样本数，包含峰值后的恢复阶段，不等同于削波次数。

不保存、输出或上传 PCM 内容。离线测试只生成合成波形。
